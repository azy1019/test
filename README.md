# 妙记（Android 自动记账）

妙记是一款数据完全保存在手机本地的 Android 记账 App。用户付款成功后，它通过用户主动开启的无障碍服务读取微信或支付宝当前结果页，自动识别金额并弹出用途选择；只有用户确认用途后才写入账本。它也支持手动补记与 CSV 导出。

## 已实现

- 本月支出、收入、结余与分类占比
- 账单明细、分类筛选、长按删除
- 手动记录收入和支出
- Android 无障碍服务授权引导
- 微信、支付宝付款结果页金额识别与防重复弹窗
- 付款后手动选择用途并确认入账
- CSV 文件导出（UTF-8 BOM，可直接用 Excel 打开）
- 账本不做云备份；无网络权限

## 构建与运行

1. 安装 Android Studio，确保 SDK 33 和 JDK 11 可用。
2. 用 Android Studio 打开本目录，等待 Gradle 同步完成。
3. 连接 Android 8.0 或更高版本的手机，运行 `app`。
4. 首次进入后点击首页的“去开启”，在系统“无障碍”设置中开启“妙记自动记账”。

命令行构建需要 Gradle 7.5.1；执行 `gradle assembleDebug` 后，APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 无需本机 SDK 的云端构建

项目已包含 `.github/workflows/build-apk.yml`。把项目上传到 GitHub 后：

1. 打开仓库的 **Actions** 页面。
2. 选择 **Build Android APK**，点击 **Run workflow**。
3. 构建完成后，在运行页面底部下载 `miaoji-debug-apk`。
4. 解压后得到可安装的 `app-debug.apk`。

该流程使用 GitHub 托管的 Android 环境，不需要在当前电脑安装 Android Studio 或 Android SDK。

## 自动记账边界

自动记账只在无障碍服务开启后处理微信和支付宝当前显示的付款成功页面，无法补录历史账单。识别到金额后会显示用途确认弹窗，不会直接入账；关闭弹窗即可放弃。支付应用升级或页面文案变化时，可能需要补充识别规则。

## 隐私设计

项目未声明网络权限。无障碍服务仅限定于微信和支付宝，读取当前付款页面的可见文字，不执行自动点击或输入。页面文字在本机内存中解析，用户确认后只把金额、用途、商户和时间等账单字段写入本地 SQLite；原始页面内容不落盘。数据库明确排除在 Android 云备份之外，但换机直连迁移时允许随设备数据转移。
